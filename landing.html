Presensi QR Code Cepat, Ringan, & Terhubung Google Sheets

Absen QR General dibuat khusus untuk membantu panitia mendata kehadiran peserta pada acara satu hari maupun rangkaian multi-sesi. Cukup buka browser di HP panitia untuk memindai tiket QR—tanpa install aplikasi Play Store, tanpa database server sewa, dan tetap aman saat sinyal drop di lapangan.

Kelebihan Nyata Berdasarkan Arsitektur Code.gs

Fitur yang benar-benar ada di dalam kode backend script, dirancang dari pengalaman menangani antrean riil.

Panitia Bebas Install APK

Petugas gate tidak perlu download file APK atau aplikasi tambahan. Cukup buka tautan web di browser HP panitia mana pun dan beri izin kamera.

Semua Data Milik Google Sheets Anda

Tidak ada database pihak ketiga. Semua data nama, waktu presensi, petugas, dan gate langsung tercatat rapi di Google Spreadsheet privat akun Google Anda.

1 QR Tetap untuk Seluruh Sesi

Peserta cukup mendaftar satu kali dan memegang 1 tiket QR. Tiket yang sama otomatis berlaku untuk Sesi 1, Sesi 2, hingga penutupan tanpa perlu ganti tiket.

Mendukung Masuk & Keluar (IN-OUT)

Didukung oleh Code.gs: sesi bertipe CHECK_IN_OUT mencatat waktu check-in sekaligus check-out sehingga panitia tahu siapa yang masih ada di lokasi.

Nol Kuota Email (Drive Sharing)

Di Code.gs, tiket QR otomatis di-share via Google Drive viewer (grantDriveViewerSmart). Muncul di Google Drive pendaftar tanpa menghabiskan kuota email harian Google!

Fitur Pembatalan (Undo Scan)

Bila panitia salah memindai tiket atau salah memilih sesi, kehadiran bisa langsung dibatalkan (action=cancelCheckIn) dengan catatan audit trail tercatat di sheet.

Panduan Setup Berdasarkan Code.gs

Ikuti alur resmi Code.gs untuk mengaktifkan seluruh fitur otomatisasi menu, generate QR, dan sinkronisasi presensi.

1

1. Buka Apps Script di Google Spreadsheet Anda

Buka Google Sheets yang akan Anda jadikan database presensi. Pada menu atas, klik Ekstensi > Apps Script (Extensions > Apps Script).

Pastikan Anda login menggunakan akun Google pemilik spreadsheet agar deployment memiliki izin penuh.
2

2. Pasang File Script Backend (Code.gs & Dashboard.gs)

Di editor Google Apps Script, buat 2 file script berikut (salin dari repositori atau unduh dari tombol di bawah):

  • Code.gs: Berisi logika registrasi otomatis, trigger Google Form, pembuatan QR tiket, check-in, check-out, pembatalan kehadiran, dan menu spreadsheet.
  • Dashboard.gs: Berisi kompilasi data realtime, agregasi per kategori/gender, dan kalkulasi riwayat sesi untuk dashboard.
Unduh Code.gs Unduh Dashboard.gs
3

3. Gunakan Menu Otomatis Spreadsheet ("⚡ Absen QR General")

Setelah script disimpan dan spreadsheet di-refresh, akan muncul menu baru di atas Google Sheets: ⚡ Absen QR General. Klik menu tersebut untuk inisialisasi 1-klik:

Menu Bawaan onOpen() di Code.gs
• 🚀 1. Setup Otomatis (Inisialisasi Seluruh Sheet & Pasang Trigger)
• 📝 2. Buat Google Form Pendaftaran Otomatis (Opsional)
• 📥 3. Impor Peserta Lama dari Form Responses (Jika ada data eksisting)
• 🔗 4. Buka / Bagikan Link Scanner Panitia
Fungsi autoSetupEverything() otomatis membuat tab Data Peserta, Master Sesi, Log Kehadiran, dan folder Drive QR Code Peserta tanpa perlu Anda buat manual satu-satu!
4

4. Deploy sebagai Web App (Aplikasi Web)

Agar kamera HP panitia bisa mengirim hasil scan ke sheet, terapkan script sebagai Web App:

  • Klik tombol Deploy > New deployment (Terapkan > Deployment baru).
  • Pilih jenis deployment: Web app (Aplikasi Web).
  • Execute as: Me (email Google Anda).
  • Who has access: Anyone (Siapa saja). (Wajib agar panitia bisa scan tanpa login akun Anda!)
  • Klik Deploy, lakukan Review Permissions, lalu salin Web App URL yang dihasilkan (format: https://script.google.com/macros/s/.../exec).
5

5. Hubungkan ke Web Scanner & Dashboard

Buka Web Scanner (index.html) atau Dashboard (dashboard.html):

  • Klik ikon Pengaturan (Gear) di pojok kanan atas.
  • Tempelkan URL Web App tadi ke kolom URL Google Apps Script.
  • Klik Simpan Pengaturan. Selesai! Web scanner akan langsung menampilkan nama sesi yang aktif dan siap digunakan scan tiket QR.
