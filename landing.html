Presensi QR Code Cepat, Ringan, & Terhubung Google Sheets

Absen QR General dibuat khusus untuk membantu panitia mendata kehadiran peserta pada acara satu hari maupun rangkaian multi-sesi. Cukup buka browser di HP panitia untuk memindai tiket QR—tanpa install aplikasi Play Store, tanpa database server sewa, dan tetap aman saat sinyal drop di lapangan.

Kelebihan Nyata Berdasarkan Arsitektur Code.gs

Fitur yang benar-benar ada di dalam kode backend script, dirancang dari pengalaman menangani antrean riil.

Panitia Bebas Install APK

Petugas gate tidak perlu download file APK atau aplikasi tambahan. Cukup buka tautan web di browser HP panitia mana pun dan beri izin kamera.

Semua Data Milik Google Sheets Anda

Tidak ada database pihak ketiga. Semua data nama, waktu presensi, petugas, dan gate langsung tercatat rapi di Google Spreadsheet privat akun Google Anda.

1 QR Tetap untuk Seluruh Sesi

Peserta cukup mendaftar satu kali dan memegang 1 tiket QR. Tiket yang sama otomatis berlaku untuk Sesi 1, Sesi 2, hingga penutupan tanpa perlu ganti tiket.

Mendukung Masuk & Keluar (IN-OUT)

Didukung oleh Code.gs: sesi bertipe CHECK_IN_OUT mencatat waktu check-in sekaligus check-out sehingga panitia tahu siapa yang masih ada di lokasi.

Nol Kuota Email (Drive Sharing)

Di Code.gs, tiket QR otomatis di-share via Google Drive viewer (grantDriveViewerSmart). Muncul di Google Drive pendaftar tanpa menghabiskan kuota email harian Google!

Fitur Pembatalan (Undo Scan)

Bila panitia salah memindai tiket atau salah memilih sesi, kehadiran bisa langsung dibatalkan (action=cancelCheckIn) dengan catatan audit trail tercatat di sheet.

Batasan Teknis & Kuota Resmi Google Platform

Transparansi teknis arsitektur Google Sheets + Apps Script agar tim panitia siap mengantisipasi lonjakan antrean, kuota server, dan karakteristik lapangan.

Pahami Plafon Resmi Infrastruktur Google Cloud
Menggunakan Google Sheets sebagai database sangat menguntungkan karena 100% gratis dan data mudah diedit panitia. Namun, Google menerapkan kuota server (*hard quotas*) yang wajib diperhatikan jika acara Anda melibatkan banyak pos/gate pemindaian serentak.
Maks 30 Thread Serentak

Eksekusi Simultan (Simultaneous Executions)

Google membatasi maksimal 30 eksekusi script aktif bersamaan per script (baik akun Gmail maupun Workspace). Jika ada 10+ gate yang men-scan serentak dan tertahan oleh koneksi internet yang lambat, request ke-31 ke atas dapat ditolak oleh Google dengan error HTTP 429 Too Many Requests.

🛡️ Solusi di Program: Menggunakan Batch Background Sync (merapel hingga 15 scan sekaligus) dan Instant Cache sehingga jumlah request HTTP berkurang hingga 90%.

Dokumentasi Quota Google Apps Script
90 Mnt (Gmail) / 6 Jam (Workspace)

Total Waktu Eksekusi Script (Runtime / Hari)

Akun Gmail gratis (@gmail.com) memiliki total kuota runtime 90 menit per hari di seluruh eksekusi script. Untuk akun Google Workspace, batasnya 6 jam per hari. Jika kuota habis, seluruh fungsi Apps Script akan berhenti sampai reset jam 00:00 PST.

🛡️ Solusi di Program: Micro-Locking (< 300ms) dan operasi logging di luar lock memangkas durasi script. Untuk event skala besar (> 1.000 peserta), gunakan akun Google Workspace.

Dokumentasi Runtime Limitations Google
Timeout Kunci: 27 Detik

Antrean Kunci Spreadsheet (LockService)

Agar baris presensi tidak saling timpa (*race condition*), backend memakai LockService. Batas waktu tunggu antrean disetel 27 detik (tryLock(27000)). Jika antrean tertahan melebihi 27 detik saat server Google lambat, server akan mengembalikan respon SERVER_BUSY.

🛡️ Solusi di Program: Data scan tidak hilang dari HP panitia! Data tetap aman di localStorage.absen_sync_queue dan otomatis dicoba ulang (*auto-retry*) setiap 3,5 detik.

Dokumentasi Google LockService
Khusus Akun Google Drive

Distribusi Tiket QR (Pengguna Non-Gmail)

Sistem menggunakan trik 0 kuota email via DriveApp.addViewer() sehingga tiket otomatis muncul di Google Drive pendaftar pada tab "Shared with me". Namun bagi peserta yang mendaftar memakai email Yahoo, Outlook, atau iCloud, tiket tidak akan muncul jika email tersebut tidak tertaut ke akun Google.

🛡️ Solusi di Program: Tautan file Google Drive tersimpan di kolom sheet Data Peserta. Panitia dapat membagikan link via WhatsApp blast atau peserta login Google dengan email tersebut.

Dokumentasi Google Drive Sharing
Batas Memori: ~5 MB

Penyimpanan Cache Lokal HP (LocalStorage)

Untuk memungkinkan scan super cepat 0.05 detik dan pencarian offline, database peserta di-download ke browser HP panitia. Mayoritas browser smartphone membatasi penyimpanan localStorage sebesar ~5 MB per origin.

🛡️ Solusi di Program: Struktur JSON dirancang ramping (hanya ID, Nama, Sesi), aman untuk 3.000–5.000 peserta. Tersedia tombol "Bersihkan Cache Lokal" di Pengaturan untuk mereset memori HP setelah acara selesai.

Spesifikasi MDN Web Storage API
Batas Maks: 10 Juta Sel

Kapasitas Dokumen (Google Sheets Limits)

Batas Google Sheets adalah 10.000.000 sel per dokumen. Kendala yang lebih nyata adalah penurunan kecepatan kalkulasi jika ada ribuan formula COUNTIF aktif bersamaan saat sheet dibuka langsung di browser admin.

🛡️ Solusi di Program: Arsitektur 4-sheet memisahkan tab audit trail (Log Kehadiran) dari tab matriks kehadiran (Data Peserta), mencegah penumpukan formula berat.

Panduan Setup Berdasarkan Code.gs

Ikuti alur resmi Code.gs untuk mengaktifkan seluruh fitur otomatisasi menu, generate QR, dan sinkronisasi presensi.

1

Buka Apps Script di Google Spreadsheet Anda

Buka Google Sheets yang akan Anda jadikan database presensi. Pada menu atas, klik Ekstensi > Apps Script (Extensions > Apps Script).

Pastikan Anda login menggunakan akun Google pemilik spreadsheet agar deployment memiliki izin penuh.
2

Pasang File Script Backend (Code.gs & Dashboard.gs)

Di editor Google Apps Script, buat 2 file script berikut (salin dari repositori atau unduh dari tombol di bawah):

  • Code.gs: Berisi logika registrasi otomatis, trigger Google Form, pembuatan QR tiket, check-in, check-out, pembatalan kehadiran, dan menu spreadsheet.
  • Dashboard.gs: Berisi kompilasi data realtime, agregasi per kategori/gender, dan kalkulasi riwayat sesi untuk dashboard.
Unduh Code.gs Unduh Dashboard.gs
3

Gunakan Menu Otomatis Spreadsheet ("⚡ Absen QR General")

Setelah script disimpan dan spreadsheet di-refresh, akan muncul menu baru di atas Google Sheets: ⚡ Absen QR General. Klik menu tersebut untuk inisialisasi 1-klik:

File Edit Tampilan Ekstensi ⚡ Absen QR General
1. Setup Otomatis (Inisialisasi Seluruh Sheet & Pasang Trigger)
2. Buat Google Form Pendaftaran Otomatis (Opsional)
3. Impor Peserta Lama dari Form Responses
4. Buka / Bagikan Link Scanner Panitia
Fungsi autoSetupEverything() otomatis membuat tab Data Peserta, Master Sesi, Log Kehadiran, dan folder Drive QR Code Peserta tanpa perlu Anda buat manual satu-satu!
4

Deploy sebagai Web App (Aplikasi Web)

Agar kamera HP panitia bisa mengirim hasil scan ke sheet, terapkan script sebagai Web App:

  • Klik tombol Deploy > New deployment (Terapkan > Deployment baru).
  • Pilih jenis deployment: Web app (Aplikasi Web).
  • Execute as: Me (email Google Anda).
  • Who has access: Anyone (Siapa saja). (Wajib agar panitia bisa scan tanpa login akun Anda!)
  • Klik Deploy, lakukan Review Permissions, lalu salin Web App URL yang dihasilkan (format: https://script.google.com/macros/s/.../exec).
5

Hubungkan ke Web Scanner & Dashboard

Buka Web Scanner (index.html) atau Dashboard (dashboard.html):

  • Klik ikon Pengaturan (Gear) di pojok kanan atas.
  • Tempelkan URL Web App tadi ke kolom URL Google Apps Script.
  • Klik Simpan Pengaturan. Selesai! Web scanner akan langsung menampilkan nama sesi yang aktif dan siap digunakan scan tiket QR.
